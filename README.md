# Ghero-MKII
Ghero MKII Guitar controller using a Lilygo T-Energy S3 (or any ESP32 really)

Successor project to https://github.com/bryan065/GHero20-Files

- MKII-1 is a rebuild of the original guitar above
- MKII-2 is a rebuild of a Wii RB3 Stratocaster

Libraries required:

- "ESP32-BLE-Gamepad" by lemmingDev (https://github.com/lemmingDev/ESP32-BLE-Gamepad)
- "Battery_18650_Stats" by Danilo (https://github.com/danilopinotti/Battery18650Stats)
- "InterruptButton" by rwmingis (https://github.com/rwmingis/InterruptButton)
